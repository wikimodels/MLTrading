# EMA Fan Breakdown — стратегия «поломка бычьего веера → шорт»

## Идея

У растущей монеты скользящие средние стоят **веером**: EMA21 (быстрая) выше
EMA50, EMA50 выше EMA100. Это «бычий веер» — признак здорового восходящего
тренда.

Пролив имеет **анатомию**: веер ломается не сразу, а по этапам:

```
S1: EMA21 < EMA50            первая трещина (шумная, слабый сигнал)
S2: EMA21 < EMA100           быстрая под длинной (средний сигнал)
S3: EMA21 < EMA50 < EMA100   полная поломка, медвежий порядок → ПРОЛИВ
```

**Сигнал — полная поломка (S3):** первый бар, когда после бычьего порядка
EMA21 < EMA50 < EMA100. После этого движение вниз реально начинается.

**Вход:** шорт монеты, у которой впервые сломался веер (S3), по открытию
следующего бара.
**Выход:** через N баров (10 дней оптимально).
**Комиссии:** taker 0.05% + slippage 0.03% за сторону.

## Связка с RVWAP Rebound (лонг-отскок)

Обе стратегии дополняют друг друга как полный цикл пролива:
1. **EmaFan (эта стратегия):** веер ломается → шорт на 10 дней → берём
   движение вниз (пролив).
2. **RVWAP Rebound:** после пролива монета лежит глубоко ниже своей 7д
   средней (−20%) → лонг-отскок на 2 дня → берём возврат к средней.

Логически стыкуются: конец пролива (10д) ≈ начало глубокой перепроданности
относительно RVWAP. Проверка точного пересечения — в работе.

## Почему это не переобучение

1. **Оба периода в плюсе** на холде 10д (1d: +5.55/+4.63; 4h: +1.62/+3.20).
2. **Альфа к BTC положительна на обоих периодах** (до +9.9% на 1d) — эффект
   не бета: монеты падают сильнее рынка после поломки веера.
3. **Экономическая логика**: полная поломка бычьего веера = тренд сменился;
   момент, когда 50 уходит под 100, — это потеря поддержки большинством
   среднесрочных трейдеров, каскад стопов.
4. Анатомия подтверждается: ранние этапы (S1) слабые, полная поломка (S3)
   — стабильная. Это согласуется с механикой пролива, а не с подгонкой.

## Риски и ограничения

- **Медиана IS на 1d ≈ 0** (+0.01%): прибыль в кризисный год собрана
  несколькими жирными проливами, а не равномерно. 50 сделок — маловато.
- **Кластеризация**: проливы синхронны (в кризис падают все монеты сразу),
  реальных эпизодов меньше, чем сделок.
- Короткие холды (1-2д) на IS — минус: **шорт держать минимум 5-10 дней**.
- Без SL/TP: позиция закрывается строго через N дней.
